# Simplify Theme · UI 重整设计与验收契约

目标是一个可长期使用的 DSH 对话工作台。沿用用户参考图的深蓝玻璃材质、分层侧栏和委派图，不把营销图里的虚构导航或任务清单注入真实会话。对话是主区域；输入是主操作；用量与子代理是从属信息。

## 布局与密度

- 保留宿主侧栏宽度、导航、消息列宽度和分屏机制；主题不重新实现应用壳。
- 顶栏沿用宿主结构，只有真正的对话头部需要表面处理，不匹配所有含 `_header` 的类。
- 输入区的附件、原生权限、插件模型/思考等级、其他插件控件、发送/停止各保留一份。只在替代模型座实际存在时隐藏原生 ModelSelect，不能隐藏整个 standardControls，也不能隐藏其他 menu 按钮。
- 输入卡片与有数据的统计栏共享边缘与材质。统计被关闭或无数据时恢复独立圆角，原生统计不受影响。
- HUD 用 CSS Grid，不用 flex-basis 数学排布。可用容器宽度 >=640px 四列；<640px 两列。在 340px 可用宽度仍保留两列；每个值可局部换行，不能把整个 HUD 变成四个全宽行。四指标时宽模式总高 <=116px，窄模式 <=196px（含耗时）；无投影不显示空托盘。
- HUD 只展示真实会话轮/步、上下文占用、端到端平均 TPS、缓存命中；耗时为轻量尾行。累计 TPS 不标为“实时”，无数据不填 0 冒充测量，缓存数字不重复前缀。上下文容量只接受当前 projected/pressure/breakdown，不用历史累计 Token 冒充；本轮耗时与模型累计耗时使用不同标签。
- 详情弹层有可访问名称、Escape/外点关闭，窄屏/短视口内可滚动。不能因 blur/transform 祖先而定位出视口。
- 委派摘要默认折叠。展开后保留顶部编排节点与弧线；根据实际容器宽度四/二/一列卡片。标题、模型、状态、实际步骤数、打开/停止操作清晰分层；不生成未经证实的“已完成清单”。主节点状态必须反映子节点聚合结果。

## 配色（单一 Token 来源）

- 画布 #0b1420；侧栏 #0a121d；一级面 #101c2b；玻璃面 #152337。
- 主文字 #e9effa；次文字 #a6b5cd；说明 #8497b3（小字避免过暗）。
- 主强调 #7aaaf0；成功 #4ee39b；警戒 #ffc46b；失败 #ff9b9b。职责色只用于委派图图标与细边。
- 保留冷色玻璃边缘和轻微染色阴影，减少多个大面积外发光。深浅主题各自成立。
- `themeOverrides` 控制全局皮肤，关闭后必须完整恢复宿主全局颜色和布局表面。Token 由 ctx.theme.overrideTokens 负责，不添加第二套硬编码变量覆盖。macOS 原生半透明侧栏可用狭窄、验证过的结构选择器覆盖其表面，颜色仍来自 token。
- 不使用全局 `[class*='_root']`、`[class*='_header']`、`[class*='_frame']` 或全局通配菜单隐藏规则；必要 CSS module 后缀匹配要受确定结构约束并有防误伤测试。

## 字体与字号

使用宿主系统无衬线字体；数字使用 tabular-nums，不引入网络字体。正文14/22px；控件13/20px、高28px；指标标签12/18px；HUD主读数22/28px；单位12/18px；图谱标题14/20px；编排节点标题16/22px；状态12/18px。缩窄时改布局而非缩小文字。

## 验收矩阵

1. 新会话/现有会话、明暗主题、themeOverrides开/关、dockStats开/关/无投影。
2. 独立组件预览与宿主结构契约测试分开命名；不能把合成壳截图描述成真实应用截图。
3. 使用宿主相同的 composer/dock slot wrapper、原生模型/权限 DOM 和布局 CSS 验证 1040/720/600/390px 内容宽度、开右侧分屏、短高度。
4. 确认只有原生 ModelSelect 隐藏；原生权限、input.right 的图像插件按钮、其他 menu 按钮可见；禁用模型替换后原生模型恢复。
5. HUD 几何断言列位置与高度，卡片与 HUD 边缘一致，开关关闭恢复圆角；详情弹层全部位于视口并可访问。
6. 委派 running/done/failed/denied、长中英文标题、1/4/8节点、折叠/展开/卸载，真实步数和状态一致。
7. 运行类型检查、单元测试、浏览器回归和构建，审查 final diff。真实桌面截图只有工具实际采集成功且验证构建版本后才可作为证据；无法采集必须保留未完成项。
